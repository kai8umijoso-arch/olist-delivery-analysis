# ZOZOのプラットフォーム運営者視点で考える配送遅延分析

## 1. プロジェクト概要

本分析では、ECにおける顧客への配送遅延とレビュー評価の関係を確認し、配送工程・販売者・商品カテゴリー別の傾向から、プラットフォーム運営者が改善対象の候補を把握し、具体的な支援策を検討するための手がかりを探る。

**データについて：** 使用しているのはOlistの公開ECデータセットであり、ZOZOの実データではない。したがって、本分析はZOZOの実際の配送状況を評価するものではなく、ZOZOのようなプラットフォーム運営者の立場を想定したケーススタディである。

### データセットの採用理由

本分析では、Olistの公開ECデータセットを採用した。このデータセットには、注文日時・配送業者への引き渡し日時・顧客への配達日時・予定配達日時に加え、レビュー評価、販売者ID、商品カテゴリーなどが含まれている。そのため、**配送工程ごとの所要日数と顧客への配送遅延の関係を確認し、さらにレビュー評価や販売者・商品カテゴリー別の傾向を関連づけて分析できる**と考えた。また、複数の販売者が商品を販売するECの注文データであるため、プラットフォーム運営者が販売者ごとの状況を把握し、改善候補を検討するという今回の分析テーマにも適している。

一方で、OlistはZOZOとは異なる事業者・サービスであり、データもZOZOの実際の運営状況を表すものではない。したがって、ZOZOの実態を直接評価するのではなく、ECプラットフォームにおける配送課題を分析するためのケーススタディとして用いる。

## 2. 分析の流れ

1. 顧客への配送遅延とレビュー評価の関係を確認
2. 遅延日数別に平均レビュー評価・低評価率を比較
3. 低評価率の悪化が大きくなる遅延日数の目安を検討
4. 配送工程を「注文から配送業者への引き渡しまで」と「引き渡し後の輸送工程」に分け、所要日数と顧客配送遅延率の関係を確認
5. 販売者別・カテゴリー別・販売者×カテゴリー別に顧客配送遅延率を比較
6. 結果から改善候補を抽出し、ZOZOの立場から具体策と追加調査の方向性を検討

### 遅延の定義

実際の顧客配達日時（`order_delivered_customer_date`）が予定配達日時（`order_estimated_delivery_date`）を超えた注文を「顧客配送遅延」と定義した。

`shipping_limit_date` は販売者側の出荷期限であり、顧客への配送遅延とは異なる指標である。本分析では顧客への配送遅延を主指標としている。

低評価は、同一注文に複数レビューがある場合に注文単位の平均レビューを算出し、その平均が2以下であることと定義した。

## 3. 主な分析結果

分析対象は95,824注文で、顧客配送遅延率は7.99%だった。

### 顧客配送遅延とレビュー評価

| 指標 | 予定日以内 | 予定日超過 |
|---|---:|---:|
| 注文数 | 88,163 | 7,661 |
| 平均レビュー評価 | 4.29 | 2.57 |
| 低評価率 | 9.19% | 53.99% |

予定日を超過した注文では、予定日以内の注文に比べて平均レビューが低く、低評価率が高かった。この結果から、顧客の評価には商品品質や価格だけでなく、商品が予定どおり届くかという配送体験も関係している可能性がある。ただし、配送遅延だけが評価低下の原因とは断定できない。

### 遅延日数別のレビュー評価

| 顧客への遅延日数 | 注文数 | 平均レビュー | 低評価率 |
|---|---:|---:|---:|
| 予定日以内 | 88,163 | 4.29 | 9.19% |
| 1日以内 | 1,280 | 4.04 | 12.27% |
| 1〜2日 | 820 | 3.73 | 19.76% |
| 2〜3日 | 536 | 3.18 | 34.33% |
| 3〜4日 | 496 | 2.68 | 50.40% |
| 4〜5日 | 436 | 2.50 | 55.96% |
| 5〜6日 | 434 | 2.19 | 64.52% |
| 6〜7日 | 407 | 1.81 | 76.66% |

遅延が長くなるにつれて、概ね平均レビューが低下し、低評価率が上昇する傾向が見られた。

### 低評価率の悪化を抑えるための遅延日数の目安

遅延した注文を「2日以内」と「2日超」に分けて比較した。

| 配達状況 | 注文数 | 平均レビュー | 低評価率 |
|---|---:|---:|---:|
| 予定日以内 | 88,163 | 4.29 | 9.19% |
| 遅延2日以内 | 2,100 | 3.92 | 15.19% |
| 遅延2日超 | 5,561 | 2.06 | 68.64% |

2日超の群の低評価率は、2日以内の群より53.45ポイント高く、約4.52倍だった。2日以内の群でも予定日以内の群より低評価率は高いが、2日を超えた群では低評価率が大きく上昇していた。

この結果から、遅延が発生した注文については、**3日目に入る前（予定日から2日以内）に配達を完了させることを、顧客評価の大幅な悪化を避けるための優先的なリカバリー目標**とする案が考えられる。これは2日間の遅延を許容するという意味ではない。予定日を超過した時点で顧客への通知や状況確認を開始し、特に48時間を超えそうな注文を優先して対応するという考え方である。また、2日以内なら低評価を防げると保証するものではなく、今回の観察データに基づく暫定的な運用目安である。

### 配送工程別の傾向

| 工程 | 予定日以内の平均日数 | 予定日超過の平均日数 |
|---|---:|---:|
| 注文→顧客配達（全体） | 10.88日 | 31.38日 |
| 注文→配送業者引き渡し | 3.00日 | 5.82日 |
| 引き渡し→顧客配達（輸送） | 7.89日 | 25.56日 |

注文から配送業者への引き渡しまでの日数別の顧客配送遅延率は、1日以内で3.98%、1日超〜2日以内で5.86%、2日超〜3日以内で7.16%、3日超で11.83%だった。引き渡し後の輸送工程では、12日超のグループの顧客配送遅延率が25.93%だった。

両工程とも顧客配送遅延との関係が見られた。ただし、輸送工程は主に配送業者が担うため、販売者別の輸送日数を比較して販売者の問題とみなすことは避けた。輸送工程の改善には、配送地域・配送業者・配送ルートなどの追加分析が必要である。

引き渡し前工程に時間を要する注文群では、顧客への配送も予定日を超過しやすい可能性がある。そのため、ZOZOには販売者ごとの出荷状況や出荷期限の遵守状況をモニタリングし、出荷に時間を要している可能性のある販売者を早期に把握することが求められる。ただし、所要日数の長さだけで販売者に原因があると判断せず、在庫・梱包・集荷手配などの状況を追加で確認する必要がある。

### 販売者・カテゴリー別の候補抽出

注文数30件以上の販売者623者、カテゴリー63種類、販売者×カテゴリー625組み合わせを比較対象とした。

- カテゴリー別では、家具・マットレス関連（37件、13.51%）、ファッション下着・ビーチウェア（116件、12.93%）、オーディオ（345件、12.75%）などで相対的に高い遅延率が見られた。
- 販売者×カテゴリー別では、販売者 `835f0f7810c76831d6c7d24c7a646d4d` の家庭用品カテゴリーが34件中11件遅延、遅延率32.35%だった。

これらは改善対象となる可能性のある候補であり、遅延原因を特定した結果ではない。特に件数の少ない組み合わせは、遅延率と注文数を併せて確認する必要がある。

## 4. ZOZOの立場から考えられる具体的なサービス改善案

1. **遅延時間に応じた段階的なアラート・対応基準**：予定日を超過した時点で顧客へ状況を通知し、販売者には出荷・配送状況の更新を求める。遅延24時間時点で販売者に理由と新しい配達見込みの入力を依頼し、48時間を超える可能性がある注文はZOZOのサポート画面で「優先対応」に切り替える。
2. **販売者向け出荷状況ダッシュボード**：販売者ごとに、注文から配送業者への引き渡しまでの平均日数、出荷期限超過率、顧客配送遅延率、注文数を週次で表示する。同じカテゴリーの平均や全体平均と比較できるようにする。
3. **遅延理由の入力と改善タスクの自動提示**：遅延理由を「在庫切れ・入荷待ち」「検品・梱包の遅れ」「集荷依頼の遅れ」などから選択してもらい、理由に応じて在庫連携頻度や集荷手順の見直しを提案する。
4. **販売者・カテゴリー別の重点支援**：注文数が一定以上あり、遅延率が継続的に高い販売者や販売者×カテゴリーの組み合わせを月次で抽出し、原因を確認したうえで改善計画を作成する。
5. **長期遅延顧客へのリカバリー施策**：48時間を超える遅延が見込まれる場合は、専用問い合わせ窓口や注文状況の優先更新を提供する。必要に応じてクーポン・ポイント付与などの補償策も検討する。
6. **施策の効果検証**：支援前後の出荷所要日数、顧客配送遅延率、2日超遅延率、低評価率を比較する。「遅延発生後2日以内に配達完了できた割合」や「2日超遅延率」をKPI候補とする。

これらは実施済みの施策ではなく、分析結果をもとにした提案である。実際のサービス改善には、販売者へのヒアリングや在庫・出荷・配送地域などの追加データによる原因分析が必要である。

## 5. 分析上の限界

- 本データはOlistの公開データであり、ZOZOの実データではない。
- 配送完了済みで実際・予定配達日時とレビュー評価が得られる注文を対象としているため、未配達・キャンセル注文は主分析に含まれない。
- 同一注文に複数レビューがある場合は平均値を注文の代表評価とし、低評価は注文単位の平均レビューが2以下と定義した。
- レビュー評価には配送以外の要因も影響するため、配送遅延と評価の差から因果関係は判断できない。
- 1注文に複数販売者の商品が含まれる場合、その注文は各販売者の集計に関連づけられる。
- 30注文以上という基準は少数データを避けるための目安であり、統計的な確実性を保証するものではない。
- 「遅延2日以内／2日超」の比較は、今回のデータで低評価率の差が大きかった区分を運用上の検討材料として示したものであり、2日がレビュー低下の因果的な境界であることや、2日以内なら低評価を防げることを意味しない。
- 販売者・カテゴリーの遅延率が高い理由を明らかにするには、地域・商品特性・配送業者・注文時期・在庫状況などの追加情報が必要である。
